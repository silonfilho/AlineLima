AlineLima is a responsive website created for my mother’s sewing atelier. The project presents her work with dresses, custom garments, alterations, and clothing
repairs, giving customers a simple way to learn about her services and contact her.
Built with HTML, CSS, and vanilla JavaScript, the website runs entirely in the browser without a backend, database, or external framework. Its styles, scripts, and
SVG illustrations are included in a single index.html file, making it easy to maintain and deploy as a static website.
The visual identity reflects the craft of sewing through garment sketches, pattern illustrations, fabric details, and subtle stitching animations. The color palette
combines soft greens, muted rose, and light neutrals. A green leaf inspired by the atelier’s existing brand appears beside its name and serves as the browser favicon.
Visitors can explore the services through a gallery or list view, open descriptions of each service, and contact Aline directly through WhatsApp. The website also
links to the atelier’s Instagram account and displays its accepted payment methods: Pix and cash. Payments are arranged directly with the atelier; the website does
not process transactions.
The layout adapts to desktop and mobile screens, and animations respect reduced-motion preferences. The project can be viewed locally by opening index.html in a
browser or published through a static hosting service such as Render, with no build step required.
This project brings together web development and a family business, creating an online presence that feels personal and connected to my mother’s work.
Link to access the website: https://alinelima.onrender.com/
