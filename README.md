# AlineLima — Sewing Atelier

A responsive website developed for my mother's sewing atelier, designed to showcase her work, present her services, and make it easier for customers to get in touch.

**Live Website:** [alinelima.onrender.com](https://alinelima.onrender.com/)

## About the Project

AlineLima is a personal web development project created to establish an online presence for my mother's sewing business. The website highlights her work with dresses, custom garments, clothing alterations, and repairs, offering visitors a simple and accessible way to explore the atelier's services.

The project combines a clean, responsive interface with a visual identity inspired by the art of sewing. Every detail was designed to reflect the atelier's personality, creating a digital experience that feels welcoming, elegant, and connected to its craftsmanship.

## Features

- **Responsive Design:** Optimized for desktop computers, tablets, and mobile devices.
- **Service Showcase:** Displays sewing services through interactive gallery and list views.
- **Service Details:** Allows visitors to explore descriptions of the services offered.
- **WhatsApp Integration:** Provides direct communication with the atelier for inquiries, appointments, and service requests.
- **Instagram Integration:** Connects visitors to the atelier's official Instagram profile.
- **Custom Visual Identity:** Incorporates garment sketches, sewing patterns, fabric-inspired illustrations, and a signature green leaf from the atelier's branding.
- **Subtle Animations:** Includes stitching-inspired effects while respecting reduced-motion accessibility preferences.
- **Payment Information:** Displays the accepted payment methods, Pix and cash.
- **Lightweight Architecture:** Runs entirely in the browser without requiring external frameworks, a backend, or a database.

## Technologies Used

The website was developed using three core web technologies:

- **HTML5** — Provides the structure and content of the website.
- **CSS3** — Handles responsive layouts, typography, colors, transitions, and animations.
- **Vanilla JavaScript** — Powers interactive elements and user interactions without external libraries.

All styles, scripts, and SVG illustrations are included in a single `index.html` file, keeping the project lightweight and easy to maintain.

## Design and Visual Identity

The website's design is inspired by the creative process of sewing, combining delicate illustrations, subtle movements, and a carefully selected color palette.

Soft greens, muted rose tones, and light neutrals create a calm and elegant atmosphere. A green leaf inspired by the atelier's existing branding appears alongside its name and is also used as the website's favicon.

Garment illustrations, sewing patterns, and stitching animations reinforce the connection between the digital experience and the handmade work performed at the atelier.

The objective was to create a website that represents a real family business rather than relying on a generic commercial template.

## Getting Started

Since the project uses only HTML, CSS, and JavaScript, no installation, dependencies, or build process are required.

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Navigate to the project directory and open `index.html` in your preferred web browser.

The website will run locally without requiring a development server.

## Deployment

The project is deployed using **Render** as a static website.

Because it does not require server-side processing or a build step, it can also be hosted on other static hosting platforms, such as GitHub Pages, Netlify, or Vercel.

**Access the live website:**

https://alinelima.onrender.com/

## Contact and Payments

Visitors can contact the atelier directly through WhatsApp to ask questions, discuss garment customization, or request alterations and repairs.

The website also provides access to the atelier's Instagram profile, where customers can follow its work and updates.

Accepted payment methods include **Pix and cash**. All payment arrangements are handled directly with the atelier. The website does not process online transactions.

## Project Purpose

AlineLima was developed as both a practical web development project and a way to support my mother's business.

Beyond creating a functional website, the goal was to translate the identity of her sewing atelier into a digital space that reflects the care, creativity, and dedication behind her work.

This project represents the connection between technology, craftsmanship, and family, showing how web development can help small businesses build a meaningful online presence.
